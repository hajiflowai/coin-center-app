# 🖼️ โฟลเดอร์รูปภาพเหรียญ (Coin Images Upload Directory)

โฟลเดอร์นี้สำหรับวางไฟล์รูปภาพเหรียญ (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`)

## 🌐 การดึงรูปภาพไปใช้งานในแอป:
เมื่อคุณนำไฟล์รูปภาพมาวางในโฟลเดอร์นี้ เช่น `my_coin.jpg` 
คุณสามารถนำ URL ด้านล่างนี้ไปกรอกในแอป **Coin Center** ได้ทันที:

```
/uploads/my_coin.jpg
```

ระบบ Express Web Server จะเสิร์ฟรูปภาพผ่านเว็บแอปให้อัตโนมัติครับ!
