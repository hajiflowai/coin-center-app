# 📁 โฟลเดอร์นำเข้าข้อมูล (Data Import Directory)

โฟลเดอร์นี้สร้างขึ้นเพื่อให้คุณวางไฟล์ข้อมูลเหรียญต่างๆ สำหรับการนำเข้าเข้าสู่ระบบ **Coin Center**

## 📄 ประเภทไฟล์ที่รองรับ:
- **JSON / CSV / Excel**: ไฟล์ตารางข้อมูลเหรียญ รายชื่อเหรียญ ราคาทุน/ราคาขาย
- **Text Files (.txt / .md)**: บันทึกข้อมูล รายการเหรียญ หรือโน้ตรายละเอียดเหรียญ
- **Image Datasets**: ไฟล์รูปภาพเหรียญปริมาณมาก

---
*💡 ทิป: หากต้องการวางรูปภาพเหรียญสำหรับแสดงผลหน้าร้าน แนะนำให้วางในโฟลเดอร์ `public/uploads/` ครับ*
